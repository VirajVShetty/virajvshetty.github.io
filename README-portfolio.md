# Viraj Shetty — Portfolio

## Open
Extract the entire ZIP, then open `index.html` in a browser. Keep `resume.pdf` and the `media/` folder next to it; the project previews use relative local files.

The static site has no build step, external animation library, API key, or running app dependency. Outbound project/channel links require internet access.

## Included
- Current résumé-backed copy and downloadable PDF.
- Two original cobalt-and-white butterfly koi, based on the uploaded motion reference, with long trailing petal fins, flexible swimming bodies, pixel rendering, and two organic blue patches on each face whose shapes complement the other fish's markings. No whiskers, central symbol, or decorative blue wave spots.
- Full-home interactive water ripples. Pause/reduced-motion controls cover the fish and water animation.
- Fixed window with hidden content scrollbars, short mouse-wheel easing, native fine-trackpad/touch scrolling, and keyboard access. No outer-page scrolling; reduced-motion disables easing and forced-colors restores scrollbars.
- Home-page hover-highlight toggle.
- Automatic, crossfading slide previews only, with pause/play and full-size viewing; no GIF/video mode switch or manual slide navigation.
- Querycraft: three actual local-app screenshots. An archived GIF walkthrough is included among media files but is not a preview mode in the site.
- Financial Data Analytics: four genuine notebook chart exports in a transitioning slideshow.
- Credit-risk reporting: official thumbnail and four genuine YouTube storyboard previews.
- Project links, YouTube channel, accessible slide controls and full-size previews.

Querycraft screenshots use its explicitly synthetic, deterministic demo. The credit-report storyboard frames are low resolution. Detailed provenance and remaining inputs are documented in `CONTENT-NOTES.md`.

Jev and FP&A entries are included, but their demo links are still needed. No substitute results were invented.

`project-showcase.json` is a readable manifest of the embedded showcase content and media. The HTML embeds the same data so it works directly from a file; changes to the manifest must also be synchronized into the HTML.
